## [1.0.0] - 2024-xx-xx

### Added
- Backend principal con Express + MongoDB
- Backend API secundario para app móvil
- Frontend web con EJS templates
- Sistema de autenticación de administradores
- Catálogo de películas y series con TMDB
- TV en vivo con reproductor HLS
- Scraper automático en Python
- Panel de administración
- Proxy para YouTube
- PWA (Progressive Web App)
- Chat en tiempo real con Firebase
- Sistema de favoritos e historial
- Soporte multi-servidor

### Features Destacadas
- Reproductor IPTV con calidad adaptable
- Fallback automático de streams
- Scraping automático cada 2 horas
- Integración completa con TMDB
- API REST para aplicación Android
